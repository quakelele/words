WORDS: React + Vite. RU / EN.

Deploy: install Node.js 22.13+; open this folder in a terminal; run npx vercel@latest --prod. Sign in, create a new project named words, use current directory. Vercel settings are included in vercel.json.

Local: npm install; npm run dev. Build: npm run build.

Before switching domains, export your words from the old site and import them on the new site. Browser storage is separate for each origin.
